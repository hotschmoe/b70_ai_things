# S116 selected candidate ISA review obligations

SOURCE ONLY. This is a worksheet, not an observed compiled PASS. Actual CPU
binding/control comparison precedes a separately authorized candidate decode.

1. Six actual host functions ->Info/cache/guard ->linked name pointer ->unique
   selected image. Distinct classes/cells; inspect true control/candidate host
   choice and correct GrMulti arguments. Static binding is not device dispatch.
2. Original control UP/reduce: exact S115 computational prefixes ending at
   82848/16272, normalized execution/payload metadata, options, constant data
   and relocation bytes. Raw complete image/text identity is reported separately.
   A mismatch HOLDS; root inspects differences before any further decode/GPU.
   Norm/down have exact source projection only, no invented original binary proof.
3. Candidate reduce: trace original80-slice accumulator operations and raw
   m.part store operand. It must retain the exact materialized FP32 bits for the
   extra +0 input, including if the source reload is compiler-forwarded. Record
   exact register/accumulator widths, payload pointer/row ownership and store
   ordering. No wider/private value may silently replace the published raw value.
4. On that value: new +0 add ->source /HC lowering ->unary minus/native exp
   lowering ->denominator +1 ->final division/refinement ->owner lo store. Compare
   ordered dataflow and modes against actual old UP. S115 observed +0@1072,
   scale@1720 (mul0.25), exp1744, invm1792/1968 and14 madm sites. These offsets
   locate the old seam, not required new instruction addresses or dynamic counts.
   Do not assume source /4 and emitted mul0.25 universally equivalent, or a
   forwarded float/store/load can never differ across FP contexts. No volatile
   reload or altered arithmetic is introduced by this audit to force a PASS.
5. Preserve original inject raw output/skip branch, untouched raw part2,
   owner/token/row mapping and inactive planes. Stage candidate owner lo through
   the original SLM/barrier; no incorrect shared owner or early store/load alias.
6. Candidate UP: remove only the old activation/global-lo prologue. Check all
   original dot8 FMA orders, second weight contribution, XOR16/8/4/2/1 butterfly,
   pending residual FMA, rv*wn*rsc, later sigmoid gates, c0..3 sum and /HC mean.
   Later math.exp/invm sites MUST NOT be mistaken for removable prologue work.
   Scheduling/register changes are explicit; identical opcode counts alone do
   not prove identical FP dependencies or operands.
7. Read actual resources/options/constants/relocations and CR0 instructions.
   S115 both OR0x400004C0 is raw evidence, not denorm/rounding interpretation.
   Missing spill/scratch/SLM/barrier fields UNKNOWN, not zero. Metadata
   barrier_count is not the number of static sync.bar instructions. Report actual
   branch/predicate/refinement sites without dynamic-cycle/SFU/traffic claims.
8. Reachable synthetic part2 tests later report actual raw-part bits; direct
   control-UP raw-part diagnostic remains control-only. No universal negative-
   zero/subnormal/nonfinite or all-input correctness conclusion follows. Strict
   anchors/graphs/guards and lifecycle/health plus actual reviewers/root GPU_GO
   still follow this compiled review; this worksheet grants none of them.
