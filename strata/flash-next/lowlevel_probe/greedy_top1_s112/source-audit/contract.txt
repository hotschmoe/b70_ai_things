Exact comparison contract, NO PENALTIES:
sampler.cpp91 returns unmodified logit for count<=0; record_post_head passes
history=null, penalty window0, greedy=true, temperature0. Its scan starts
(value=-inf,index=n_vocab), visits ascending indices per thread and takes
strictly larger values. Subgroup/local merges compare greater value, then
lower index on equality; all missing candidates finally map to0.
argmax_rows uses the SAME initial sentinel, strict scan and value/index
comparison, but partitions the row into contiguous chunks. For finite
logits, maximum+lowest-index is independent of partition/reduction tree;

so lower index wins; negative-only rows and subnormals use the same source
comparisons. This source argument is not compiled all-input proof.
