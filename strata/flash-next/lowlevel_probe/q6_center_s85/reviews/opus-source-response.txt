# GO_BOUNDED_BUILD

Build only. GPU timing is accepted only after the root ISA/resource gate below passes.

**Arithmetic identity (verified by hand)**
- Each byte is `u = (ql nibble) | (qh 2 bits << 4)`, so `u` is in 0..63.
- `u + 0x60` is at most 159, which is below 256. No byte carries into its neighbour, so the packed 32-bit add equals four independent byte adds.
- XOR 0x80:
  - For u \u2265 32, the byte is at least 128, and XOR subtracts 128, giving u\u221232.
  - For u < 32, the byte is in 96..127, and XOR gives u+224, which is u\u221232 (mod 256).
  - Read as int8, both cases equal the original `sub_sat(u, 0x20)`, which never saturates for u in 0..63.
- The `vi1` path applies the same masks and shifts. The `bit_cast` from uint32 is well defined.
- Integer `vi` values are identical, so the dp4a order, FP ledger and XOR reduction are unchanged by construction.

**Unchanged structure**
- The A2 loads, the Q8 int loads (offset 4, 4-byte aligned), NCOLS=6, RPW=1, SG=32 with `reqd_sub_group_size`, and the WARPS=4 launch are textually identical across `CAND`.
- `load16_a2` reads `q[1]` only for unaligned addresses, so it cannot run past the end of the allocation.

**Harness**
- **Gate order:** public is checked against the saved S44 anchor first, then original against public, then candidate, for both the original and changed inputs. Repeat, restore, single and batch20 graphs follow. All shapes pass correctness before any timing starts.
- **Per-snapshot checks:**
  - guards on all four buffers;
  - float input, weights and Q8 read back unchanged;
  - output tail still 0xFF;
  - all outputs finite.
- **Saved fixtures:** the 8-column S44 Q8 fixture is truncated to its first 6 columns, and the inactive S44 output tail is checked to be 0xFF.
- **Analysis cross-checks:**
  - 73 phases per shape (26 + 9 + 6 + 32);
  - OCCO/COOC slot order mirrors the leaf;
  - DOT checks require exactly 1 or 20 kernel nodes, a linear chain, kernel-name binding, three nonzero pointers per node, and the same pointers across all arms;
  - per-round paired means are recomputed.
- **Prelink reuse:** `/common/mmvq-core.images.o` and the frozen libraries are linked unchanged. The container sha256 is checked before and after the build.
- **Leased run:**
  - one process, no retry;
  - a timeout stops only the container ID recorded in the cidfile;
  - post-health is held until removal is confirmed;
  - post-identity runs only after analysis passes.

**Build-gate conditions (resolve before any GPU work, not code changes)**
1. **No ISA/resource audit in the script yet.** `build-container.sh` has no ISA or resource step. Before card0, the root gate must extract both `PrivateC6` kernels from `leaf.images.o` and show:
   - candidate and original have the same GRF mode, spill (0 or equal) and SIMD32;
   - the candidate's only diff is replacing the sub_sat sequence with add+xor, with nothing else changed;
   - the public symbol resolves from the common8f prelink, with no duplicate device image in the leaf.
2. **DOT kernel-name patterns are unverified.** The regex fragments `native_mmvq_q6k_wide_a2`/`ILi6EE` and `PrivateC6ILb0EE`/`ILb1EE` must match the real mangled names. A mismatch fails safely but wastes the lease, so confirm them against `symbols.txt` offline.
3. **Compile flags must match common8f.** Confirm that `-DSTRATA_XMX_SG16`, `STRATA_Q6K_EXPERTS` and `-fp-model=precise` match the common8f build. Mismatched headers would make the native types and constexprs differ between leaf and library (an ODR/ABI risk).
4. **Pinned scripts not in the packet.** `runtime_identity.py` and the pins file can only be audited through the pin hash. The root must confirm that hash before the lease.

No fitted tolerance is present: every comparison is byte-exact. All JSON outputs set `serving_qualified=false` and `speed_qualified=false`. Correct.
