**Verdict: HOLD** \u2014 one concrete source blocker in the private header; everything else in the packet reviews clean or is runtime-gated. Fix the blocker, re-pin the two hashes, then GO_BOUNDED_BUILD.

**Blocker (must fix before any GPU run)**

`private_tiled_scores.hpp` launches with `sycl::ext::oneapi::experimental::use_root_sync`. That property requests root-group synchronization, which requires every work-group of the nd_range to be co-resident. The launch is Y=ceil(nq/8) \xd7 X=256 work-groups of 256 work-items: 8192 work-groups for nq=256, 512 for ragged9. Neither is resident on a single BMG G31, and the extension specifies an exception when the group count exceeds `max_num_work_group_sync`. The kernel never uses a root group. Expected outcome is a deterministic runtime exception on the candidate arm (leaf exit 2) after burning a card0 lease. Remove the `props` object and pass the lambda directly to `parallel_for`. This changes the header SHA256 and `expected-source.sha256`, so the current CPU build is only useful as a toolchain dry run.

**Reviewed and sound**

- **FP tree:** tiled body is identical to the public kernel in arithmetic order: four products summed in one expression, xor 16/8/4/2/1 sub-group reduction, head0..3 ReLU accumulation, +1e9 only when b==n_bid and nkv%4!=0. Routing queries through local memory does not change values. Cross-TU contraction differences under `-fp-model=precise` are possible in principle but are caught by the strict all-score byte equality gate, which is the right anchor.
- **Tile offsets:** query advance 512 = 4\xd7128, steps advance kStepCount, scores advance stride, max_blocks=stride, out index qi\xd7max_blocks+b. Ragged tail n=min(8, nq\u2212q0) bounds staging, step loads, and the per-query loop. Scores beyond n_bid are never written, matching the inactive-poison gate.
- **Barriers/early exit:** step staging and first barrier are unconditional. `top` is computed by every thread from shared data, so the early return and second barrier are work-group uniform. Grid-stride wstride=256\xd78 with `b<=top && b<max_blocks` covers 0..50000.
- **Spare row:** `kp` is loaded unconditionally for every b up to top, so row n_bid must exist. Max n_bid is 50000 and POOL=50001 includes row 50000; the trailing guard remains untouched. Loads of that row are dead when b==n_bid. The +1 justification holds for this leaf only.
- **Active domain:** active=last/4+1 equals max n_bid+1, asserted per step and below stride. The candidate ignores active and derives its bound from steps, which is consistent within the validated host domain.
- **Anchors:** public arm sets expected; candidate must match full valid cells; repeat, sign-flipped, and restored states all compared; known block0 score of the last query distinguishes work from no-op (1 then 0). Poison before every call, readonly on query/steps/pooled/dead, guards on all buffers, all before any timing. Timing orders match analyze.py.
- **Build/link:** frozen object compared byte-for-byte to the archive member before and after; separate `-fsycl-link` for both objects with identical AOT target, then a plain host link with `-lsycl` and the wrapped image objects. This is the supported separate-device-prelink flow; identity.py's host-link term scan is the correct check that no AOT occurs at link.
- **Lease hygiene:** own-CID-only stop/kill, removal confirmed by enumeration before post-health, no retries, closure recorded.

**Secondary concerns (not blockers)**

- **ID-range gate exposure:** for nkv%4==0 queries, block n_bid is empty and the dead vector here is random, not production-like. If public topk can select that block, IDs \u2265 nkv will trigger a strict failure attributable to the harness, not the candidate. Confirm topk's handling before the run or accept this as a possible false HOLD.
- **Loop efficiency:** `kd` is reloaded from global memory on every block iteration though it is loop-invariant; hoist above the loop. `#pragma unroll` on the runtime-bounded nq loops is inert.
- **Alignment:** float4 reinterpret of group-local memory assumes 16-byte alignment, inherited from the public multi body; the leaf's strict gates would surface a fault.
