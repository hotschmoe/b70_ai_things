## S92 source: static review passes

**SLM and barriers**
- All `sq` reads (query load, score loop, and the LANE_CELL path) complete before the post-score `barrier()`.
- Probability writes go to `sq` as 768 of 3072 floats, after that barrier and before the existing post-exp barrier. They are read only after that barrier.
- Each (cell, head) has exactly one writer. `sp` scores are still read only by the exp loop. This holds statically.

**FMA order**
- `fold(c..c+3)` runs in ascending c for each head. This matches the original order.
- The masked break happens before any loads. `(r0|r1|r2|r3)<0` on `long long` is correct.
- After the break, the scalar tail is correct but never re-enters the 4-wide path. That is a performance note only.

**float4 alignment**
- The stride is 48 bytes, so it stays 16-byte aligned, and the base pointer is already used for float4 reads.

**Fixture**
- 12 cases \xd7 3 seeds = 36, all in one process, with seeds in the outer loop.
- The cap 2112 / width 2051 surrogate is covered.
- Ragged cases (widths 1, 11, 63, 65, 2051 mod 64 = 3) and masked groups (65, 1999) are covered.
- Output and full scratch are compared bitwise. Guards and read-only witnesses are checked.
- The sign-flip test confirms the query change is observable. Repeat and restore checks are included.
- The oracle row/scale indexing matches the kernel for INT8.
- No tolerance and no sweep. Accepted.

## Root conditions

**Before the CPU build**
1. `expected-source.sha256` must cover the private source, fixture, `build-container.sh`, frozen `qsa_decode_attn.dp.cpp.o` (`bbae92dc\u2026`) and frozen `public.images.o` (`df7655d8\u2026`).
2. Confirm that the S91 `public.images.o` was prelinked from the same public member hash. Also record which fixture or probe objects went into it.

**After the CPU build, before any GPU GO**
3. In `candidate.o`, `nm` must show no defined `CompileTimeKernelInfo`, guard or Info symbol named `attn_chunk_kernel_*` or `attn_merge_kernel_*` without the `s92_private_` prefix. All 11 renamed tags must be present.
4. In the final executable, `value_batch` and `qsa_decode_attn_batch` must load distinct Info and CompileTimeKernelInfo addresses. Each name pointer must resolve to its own string: `value_batch\u2026s92_private_attn_chunk_kernel_2ad0a4` versus `qsa_decode_attn_batch\u2026attn_chunk_kernel_2ad0a4`.
5. `private.images.o` must contain the s92_private 2ad0a4 image. The final link must register both images, with no duplicate kernel names. This includes any `fill` or `memset` kernels from `probe.o` that may also appear in the S91 public images. If there are duplicates or ambiguity, HOLD.
6. Read the actual resources (private/spill/scratch, GRF, SLM) for the private 2ad0a4 INT8 image. Report any scratch as static only.
7. `host-link.log` must show no duplicate-symbol warnings or weak overrides for kernel metadata.

**At runtime, under a separate GO**
8. No timing line counts unless `ALL 36 CASES PASS` appears and the exit code is 0. Per-case `PASS` timings printed before that point must be discarded.
9. `STRATA_ATTN_LANECELL` must be absent.
10. Results qualify INT8 only. They do not qualify production cap 2051, other KV modes, or the 2000-prefill/150-stream target.
