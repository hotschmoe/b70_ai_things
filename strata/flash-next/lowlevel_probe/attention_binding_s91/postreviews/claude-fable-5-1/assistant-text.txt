**S92 source and patch audit (static)**

- The class-tag renames are the right lever. The shared symbol is templated on the namespace-scope tag, so renaming all eleven tags via defines should yield disjoint weak symbols and disjoint registration strings. Function renames alone cannot do this, as S13 and S91 showed.
- The patch preserves per-head ascending-cell FMA order. Probabilities land in the retired query region after the post-score barrier and are read only after the next barrier. Writers are disjoint per cell and head, all twelve heads are covered, and the payload fits in the existing allocation, which matches the unchanged slm_size.
- Masked handling is equivalent: a negative row in a four-cell group exits the fast loop and the scalar tail skips negatives. The fast loop never resumes after the first masked group, which is benign for correctness but makes masked-case timings unrepresentative.
- Existing risk, not new: float4 reads from the query SLM assume 16-byte base alignment, the same assumption the baseline already makes.
- Only the INT8 default path is oracle-qualified. Modes 0, 2, 3, step, merge, and lane-cell are renamed but not qualified.
