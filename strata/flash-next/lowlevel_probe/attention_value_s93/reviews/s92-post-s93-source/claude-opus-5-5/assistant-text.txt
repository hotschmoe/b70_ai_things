# S92/S93 Independent Review

**Verdict: `ACCEPT_S92_AND_GO_S93_CAP_BUILD_MAIN_AFTER_CAP_PASS`**

## Executed evidence (S92)

- **Build and binding hold up.**
  - One CPU build and public AOT reuse.
  - All 11 host metadata entries are disjoint, with final-name pointers and device images separate.
  - The old S13 misbinding is correctly attributed and not repeated.
- **Strictness holds up.**
  - 36/36 cases passed with exact full output and scratch.
  - Guards, readonly, own-repeat, query sign-flip, changed-repeat and restored-bytes checks passed.
  - Health was 0 before and after; CID/NAME residue was gone and driver tee was 0.
  - All of this was established before timing was accepted.
- **Primitive timing only.**
  - Full32/2051: \u22128.47% at page 4 and \u22129.18% at page 512, with 60/60 seed pairs negative in each.
  - Masked32/1999: +2.39%, 60/60 positive. This is a real regression and correctly retained.
  - Narrow shapes are neutral or noisy.
  - None of this is serving gain or isolated-GPU proof.
- S92 is accepted as a correctly bound primitive result. It is not a throughput claim.

## Source reasoning (S93 main, unapplied)

**Template is sound.**
- The `VALUE_PIPELINE=false` default keeps the original body. Only the probability destination and the V loop are under `if constexpr`.
- Root's full-file recovery of 00bf, 49ff and d2861 confirms both branches reconstruct exactly. This is lexical proof only.

**V loop logic is correct.**
- The 4-wide group breaks on any negative row.
- The scalar tail then re-checks `srow[c] >= 0`.
- No masked row is folded, and no valid row is skipped.

**Domain is bounded twice.**
- The caller requires staged, `kv_int8`, nb==32, cap==2051 and first width == cap. Width is monotone within a chunk, so all 32 queries have width 2051.
- The wrapper re-checks the flag (literal `"1"`), LANECELL not 1, shapes, INT8 pointers, no Q4 and non-null buffers. Anything else delegates to the original entrypoint.
- Short widths, tails, decode/verify/MTP, direct pools and other formats are untouched.

**Masked regression exposure.**
- It is excluded only by the existing staged identity-table contract (`table[i]=i`, publication on `m.cs`), not by new proof.
- This is acceptable because the negative-page logic remains and S92 masked equality passed.
- It should be stated as a contract, not as a guarantee.

**Host marker.**
- The marker is a host-selection signal printed once. It is not a dispatch count.
- The tiny first-4K print cost is disclosed.

**Root must diff these against the original `qsa_decode_attn_batch` (source items, not blockers):**
- Wrapper `stride` and part offsets.
- `exp_props`/`use_root_sync`.
- Merge nd_range and argument order.
- The fp16 capability check.

Any divergence becomes a blocker. Also confirm `<cstdlib>`/`<cstdio>` are available in the TU; the compile will reveal this.
