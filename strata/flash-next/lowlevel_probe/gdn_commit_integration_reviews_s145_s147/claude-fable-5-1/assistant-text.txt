**Source checks (inference from the patch and prior pins)**

- Pointer arithmetic matches the old per-layer calls: layer stride 817152 floats equals the 128 by 48 by 128 state plus the 3 by 10240 convolution history, conv offset 786432, qkv and h stride 8 by 10240, gate and beta stride 8 by 48, owner offsets by first row, keep pointer the same commit record the old calls used. The conv grid gives one thread per channel; the state grid is the old per-layer 4 by 48 groups with the layer in the leading group dimension. S145 ran this exact wrapper against the public per-layer path with complete state bytes, so a hidden dependence on the leading group index inside the kernel bodies is excluded for this geometry.
- Math: the two existing kernel functions are called directly, no copied bodies, projection shows them byte-identical before and after. No y_dummy, z or gamma enter the state-only path and nothing new is allocated.
- Eligibility is strict to the tested domain: six rows as two distinct contiguous owner groups, MT 8, full 48-layer range, current geometry, in-order queue, literal mode values, seven disjoint float-aligned spans with overflow-checked ends, every GDN norm weight present with non-null data. Anything else takes the untouched loop. The API itself re-checks dimensions, strides, modes and queue property and returns false before launching.
- Ordering and state: keep copies from mapped memory are recorded first; both owner batches are recorded before the QSA and PLE nodes, which touch disjoint buffers; a mid-recording eligibility failure invalidates the capture through the existing end and delete path, so a partial batch plus fallback can never be replayed. The commit completion wait, PLE previous-token update, snapshot and cache observers are byte-unchanged.
- Markers and flags: process-constant flag, unique static identifier, one print after both owner calls, none on OFF.

Unproved until built: compiled scheduling and register use of the two new classes in the main TU, and any behaviour outside the tested domain, which the guards exclude rather than prove.
