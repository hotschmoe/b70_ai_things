## Provenance and immutable outputs

`full48_owned_layer3_qsa_projection_v3` inherits HC V3 and all original GDN, PLE,
FFN, other QSA layers, residual writes and head math. Before construction it
requires the original provider identity to equal the composition identity. A
single call admits only the exact prefix4 IDs, marks the producer used before
computation, and refuses subsequent calls even after computation fails.

`owned_layer3_qsa_projection_v3` saves the exact independently computed HC mixed
input and each original projection input/output. It saves Q/gate (12288), K and
V (512 each), indexer raw key (128), indexer query (512), original gamma vectors,
and the inherited gated attention used by the output projection. Files are
exclusive outputs; arithmetic never reads them back. Original Q8_0 projections
retain the inherited Q8_1 activation route; indexer BF16 weights retain F32
activation. Their original dot/reduction fidelity is still unqualified.

`owned_layer3_qsa_helper_contract_v3.recollect` rechecks exact consumed bytes,
SHA, finite values, shape/role/position/identity, actual-or-synthetic scope,
current reread/stat, and input/output associations for the complete four-row
roster. No native capture can stand in for an own HC mixed input. Actual use must
separately admit the original model provider and source guards; a provenance flag
does not itself prove an original-weight read.
