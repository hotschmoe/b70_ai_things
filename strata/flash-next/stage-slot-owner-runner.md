The runner automatically uses bin/gpu-run to hold both leases throughout health,
all runtime cases and owned cleanup. --leased is only for an already pair-leased
caller. No nested automatic gpu-run. Cases are fixed card0, card1 and pair32/16
with exact masks,64cells,3-to1 slots and82/82/92 owned registrations. case-timeout
is240s by default. Both descriptors pass to supervised commands.

Every case revalidates compiled source/plan/header/library/ABI identity. Docker
uses a unique parent/case name and exact parent+plan labels,4GiB cgroup, explicit
physical mask, pinned runtime and UR trace environment. Input oracle/build
mounts are read-only; no model weight mount exists. The runner requires normal
exit0/no OOM, retains rawJSON/log/inspect and executes the strict context/free
collector plus its negative controls. All cases must pass, not only the pair.

Parse/runtime/deadline/interruption failures stop the remaining cases and preserve
raw evidence. Cleanup verifies exact labels before removal, and never releases
the lease while an owned container remains. Forced termination/removal of a live
oracle is a qualification failure. Normal terminal container removal is expected.
The parent does not reset GPUs or mutate caches automatically.

Pre/post health uses strict per-card finite matmuls and compiled pairP2P0. A failed
strict phase records failure and skips the collective; it cannot qualify pair
health. Health command/trace/source/image/SHA/timestamps are stored, and any
owned health container surviving its supervisor is removed before lease release.
Kernel journal absence or fault signatures fail the run. Post-health remains
available even after a parse/case failure; failed numerical/raw trace status is
never changed into a pass because health recovered.

Optional --sentinel-shard observes the known4KiB buffered source page before/after
cases. This is a recurrence observation only; it is not an oracle weight identity
requirement or substitute for full hashes. The oracle loads no model and supplies
no model math/prefix/cache/concurrency/actual-batch-graph retirement qualification.
Postfree pointer-type unknown is never required. The result covers only the
preregistered slot allocator/host staging/context/isolation/rollback/resize/probe
and chronological logical-free contract.
