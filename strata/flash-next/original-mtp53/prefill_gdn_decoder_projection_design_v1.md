RESULT -> Source only. Dedicated private scratch is 55296 logical bytes per Prefill instance, counted and carved under the same immutable ON predicate; ordinary arena alignment/owned-page charges still apply. It is separate from the GDN/QSA/MoE aliased region and pending expert/dequant activity. Calls enqueue on the existing ordered owner stream. No added queue wait, GPU query or event.

The input route quantizes the actual F32 mixed rows in blocks of at most eight, then uses existing original-quant MMVQ for QKV/Z and exact decoder F32-input/BF16-weight gdn_ab_multi. The output route quantizes F32 normalized-and-sigmoid-gated y, never raw recurrence output or an expanded half. The default SYCL postkernel previously stored only the half view; the ON specialization stores its already computed F32 v without changing arithmetic. The serial fused recurrence path already writes F32 v. F32 rows are tightly packed; ld16 pads only the old half view.

VERDICT -> Candidate only, not a numerical/performance claim.
