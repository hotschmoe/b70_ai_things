runtime_binding(helper) runs ldd only on the root-admitted ELF. It records complete resolved host dependencies plus ELF interpreter, mapped Python ctypes libm actual path/hash/stat, Python executable/version, kernel, stable CPU identity, affinity and relevant loader/BLAS environment. FE_TONEAREST and gradual input/output behavioral probes are mandatory. Direct MXCSR flags are not observed for Python. Source/ELF/historical receipts and every runtime library are rehashed before and after, without discovering any model payload.

Public read-only finalized_binding(run_root, helper, build_root) returns report_sha256, source_binding, build_binding, current_host_runtime, tiny_known_answer_cases=15 and actual_adapter_cases=3. This API validates existing preserved fixtures/outputs/history against current files and host runtime; it does not rerun the helper or mutate reports. It invokes ldd and current libm behavioral probes and is CPU-only. Collectors should call it both before and after their work with the same helper and build root. Source/library/env changes fail closed. It is host validation only; device_intrinsics_qualified, full_HC_qualified and model_math_qualified remain false.
