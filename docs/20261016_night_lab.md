## Stage N5: shared expert after own experts, before ep_wait (STRATA_NIGHT_SH_LATE=1, linear verify graph)

The shared expert ran on a forked second queue; the fork/join made the verify graph non-linear and the runtime
appended ~2,226 event resets per replay (4.3 ms profiled tail per C1 window). Recording it on the main queue in
post(), after card 0's own routed experts and before the peer wait, keeps it inside the window card 0 used to spin.
RESULT -> C1 93.3 -> 96.4/95.6, C2 53.6 -> 55.0/54.9 per stream (57.0 engine), two clean reruns. One earlier crash
(SIGSEGV at first request) did not reproduce; a hung agent probe held card 1 just before that run.

## Quality gate: teacher-forced NLL (nl_ppl.py, 3 texts, 4762 tokens, decode-window path)
