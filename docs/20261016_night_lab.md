## Stage N5: shared expert after own experts, before ep_wait (STRATA_NIGHT_SH_LATE=1, linear verify graph)

The shared expert ran on a forked second queue; the fork/join made the verify graph non-linear and the runtime
appended ~2,226 event resets per replay (4.3 ms profiled tail per C1 window). Recording it on the main queue in
post(), after card 0's own routed experts and before the peer wait, keeps it inside the window card 0 used to spin.
RESULT -> C1 93.3 -> 96.4/95.6, C2 53.6 -> 55.0/54.9 per stream (57.0 engine), two clean reruns. One earlier crash
(SIGSEGV at first request) did not reproduce; a hung agent probe held card 1 just before that run.

## Stage N17: prefill grouped IQ-decode + XMX experts, XMX union attention, halves pipeline

Grouped expert kernel (agent prefill, STRATA_NIGHT_PREFILL_GROUPED=1): one launch per projection for all small
experts, native IQ blocks decoded straight into 8x16x16 fp16 joint_matrix (dpas present, no spills); card 1 host
enqueue per layer 2-4x lower. XMX prefill QSA attention (agent attn, STRATA_NIGHT_PATTN_XMX=1): 8 neighbouring queries
attend over the union of their selected cells with per-query masks; 1.3-2.8x per layer. Halves pipeline (agent
prefill, STRATA_NIGHT_PREFILL_HALVES=1): each chunk as two halves interleaved per layer so card 1's experts hide under
card 0's attention of the other half.
RESULT (4K / 32K tok/s, second rep): base 1342 / 1708; +GROUPED 1507 / 1738; +XMX 1567 / 1959-2009;
GROUPED+XMX **1804 / 2002-2047**; HALVES alone (no GROUPED/XMX, other binary) 1352 -> 1449 / ~1724 -> ~1834.

## What did not work (measured, keep off)

pipeline-windows 2 on SYCL (crashes); STRATA_HC_Q8 alone (no GPU path); HC persistent single kernel (grid barrier costs
more than the kernel boundary; cooperative launch fails inside SYCL graphs); router GEMV+top-10 single-kernel fusion
(slower); in-tree grouped XMX expert kernels and oneMKL gemm_batch for prefill; GDN chunkwise prefill in FP32 (4.4x slower
than the scan); pipelined persistent MMVQ (in-engine regression from slot starvation by concurrent EP kernels, likely);
EP hot-expert share; C4 depth 2 with 12-row windows; spec 5/6 at C1.
