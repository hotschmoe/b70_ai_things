## Microbench: per-kernel cost on B70 (probes/launch_tax.cpp)

Graph-replayed tiny kernel 0.55 us (eager 3.3 us). Random-data reads in a replayed graph: 1 MB 3.5 us (300 GB/s),
4 MB 8.8 us (477 GB/s), 16 MB 30 us (562), 64 MB 116 us (580). ~1.5-2 us fixed ramp/drain per kernel; 2048-WG
launches ~14 us. Constant-filled buffers read at fake 3 TB/s: Xe2 memory compression - always bench random data.

## Stage N1: HC projections Q8_0 from BF16 (STRATA_HC_Q8=1)

Upstream STRATA_HC_Q8 only read Q8_0 tensors stored in the GGUF; ISTA stores BF16, so it was a no-op.
Patch quantizes BF16 HC down/up (and the final mixer) to Q8_0 at load (ggml reference rounding), 0.63 GiB.
RESULT -> C1 91.1 -> 93.0, C2 51.2 -> 51.9/stream, coherence pass. Patch: night/patches/hc-q8-from-bf16.patch.
