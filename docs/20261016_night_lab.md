## Microbench: per-kernel cost on B70 (probes/launch_tax.cpp)

Graph-replayed tiny kernel 0.55 us (eager 3.3 us). Random-data reads in a replayed graph: 1 MB 3.5 us (300 GB/s),
4 MB 8.8 us (477 GB/s), 16 MB 30 us (562), 64 MB 116 us (580). ~1.5-2 us fixed ramp/drain per kernel; 2048-WG
launches ~14 us. Constant-filled buffers read at fake 3 TB/s: Xe2 memory compression - always bench random data.

## Stage N1: HC projections Q8_0 from BF16 (STRATA_HC_Q8=1)

Upstream STRATA_HC_Q8 only read Q8_0 tensors stored in the GGUF; ISTA stores BF16, so it was a no-op.

RESULT -> C1 91.1 -> 93.0, C2 51.2 -> 51.9/stream, coherence pass. Patch: night/patches/hc-q8-from-bf16.patch.

Card0 computes 42.6 of 57 ms per profiled C2 cycle; unprofiled host idle only ~1-1.3 ms/window. Verifier ~83 % of

## Stage N5: shared expert after own experts, before ep_wait (STRATA_NIGHT_SH_LATE=1, linear verify graph)

The shared expert ran on a forked second queue; the fork/join made the verify graph non-linear and the runtime
appended ~2,226 event resets per replay (4.3 ms profiled tail per C1 window). Recording it on the main queue in
post(), after card 0's own routed experts and before the peer wait, keeps it inside the window card 0 used to spin.
RESULT -> C1 93.3 -> 96.4/95.6, C2 53.6 -> 55.0/54.9 per stream (57.0 engine), two clean reruns. One earlier crash
(SIGSEGV at first request) did not reproduce; a hung agent probe held card 1 just before that run.
