A scope detail required for actual nested integration: prepared baselines one
and pair have different prepared.json files even when they share SDK/oracle.
Using one prepared file's receipt list for every baseline would reject the
other. sdk37_witness_scope_v1 constructs the complete declared metadata union
(up to4 prepared roots and8 total receipt inputs), requires identical nine-role
SDK/oracle corpus and current receipt SHA agreement, and makes each semantic
consumer rejoin its own declared prepared file plus the complete shared union.
Unknown prepared roots, alternate SDK/oracle or receipt mutation fail. Parent
and child build independent fresh epochs; this scope is not serialized trust.

Future integration must use a NEW source generation only after actual H48
admission. It must derive the required call set to a fixed point, make every
routed sdk_epoch keyword mandatory, and check missing plus unexpected keywords,
not only function signatures of supplied arguments. Parent seals before first
health/device work; child independently seals immediately before leaf launch;
both perform full postoperation scans before final publication. Current ELF
magic/source/header/recipe/library/health/all4/page/raw/EOF/teardown gates stay.
Source hash scans and raw/evidence hashes remain outside this byte prototype.
