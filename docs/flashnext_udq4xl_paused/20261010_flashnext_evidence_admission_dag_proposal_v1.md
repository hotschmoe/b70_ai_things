Proposed first narrow reuse boundary:

Capture all current closed upload logical logs/JSON, their original producer
receipt/oracle/plan/roster/inventory and validator source bytes in an explicit
operation-owned immutable snapshot. Validate exact current expected file roster
and original record/layout/source requirements. Execute the original logical
parse plus all three negatives once per exact case/parameter/source contract,
returning the complete result. Repeat callers still run every live or distinct
outer predicate, rejoin current expected metadata/rosters, and receive deep
copies. Original source inputs and original failed-parent scopes remain intact.

operation_evidence_snapshot_v1 captures complete bytes at entry, rereads every
byte at predevice seal and after operation, with FD/stat5/expected SHA bounds.
No saved snapshot/result can be loaded as current proof. Optional externally
unpinned log SHA is explicit, preserving the original raw-parse-vs-saved-ledger
contract rather than inventing an original publisher hash. It cannot by itself
qualify that input or permit self-consistent fabricated old proof.

Pure keys contain explicit gate name, validator file/SHA/code fingerprint,
complete typed parameters and exact input subset; each call rejoins the full
current expected epoch roster. Gate-specific undeclared byte access and
recursive same-key cycles fail. Results retain tuple/list/Boolean/numeric types,
are copied on return, and exceptions are not cached. A different validator,
parameter or input cannot borrow success. A future static port must prove ALL
file reads are routed through snapshot bytes; the prototype does not intercept
arbitrary filesystem reads or assert arbitrary user callbacks are pure.

The concrete collect_logical_free_snapshot_v1 adapter retains the original
upload logical/free subset: positive context/destructor parse, all three real
negative controls, exact saved parsed fields, owner count and empty ledger.
Outer390 source images/bounds/oracle/ABI/free/actual source4/health/teardown
still require their original predicates. No current SDK/pack/publisher check
is silently removed. Tiny real-parser fixtures run80 same callers with one
full logical subset execution; corruption and wrong owner count still fail.

Live predicates MUST NOT be memoized: lease/ownership/PID/container state,
actual health freshness and kernel chronology, current source/module identity,
original model stat/known pages, source/SDK/pack boundary checks, clock-dependent
conditions and active run state. Current before/after guards become explicit
operation barriers with fresh complete bytes and live checks; a later actual
integration must prove the same guard coverage and mark between-boundary
mutation unobserved. It cannot return cached success and label an omitted live
guard as checked. Whole private/baseline functions currently mix pure and live
work, so caching them wholesale is not authorized by this design.

Bounds:512 regular unaliased files,128MiB/file and512MiB retained bytes, lifetime
at most10800 seconds. A capture may transiently allocate an additional bounded
file-sized join buffer; no RSS/physical-memory equivalence is claimed. Failed
boundary validation prevents final qualification. Parent/child remain separate
fresh operations; no stat-only or inherited-digest trust is permitted.

VERDICT

runtime evidence, current predicate reuse, speed or model/math qualification.
Recommended next generation first consolidates the closed logical parser leaf
and repeated static metadata, with unchanged fresh live barriers. Broader DAG

semantic equivalence tests after the actual H49 outcome is retained.
