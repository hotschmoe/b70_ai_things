RESULT -> Median of the two measured batches. Cold walls:
Strata52.9417/52.5301s, vLLM Flash-Next52.0084/51.8375s,
27B122.3452/122.2375s. Effective PP divides uncached input by the interval
from first request start until all four first content arrivals. It includes
scheduling and overlapping generation; it is not an isolated kernel timer.
Cold output/wall throughput is38.84,39.44,16.75tok/s respectively.

Steady TG counts output-token arrivals only after every stream has begun
and before any stream finishes. Offline retokenization of each output must
match its server usage count512; all32 measured stream checks pass. It is
a client arrival measurement, not a generated token-ID equality proof.
The 27B yields161.5893/161.1505tok/s over12.13/12.18s four-way intervals;
vLLM Flash-Next120.8776/121.9383 over16.16/16.13s.

Strata's cold scheduling starts its fourth decode about5.1s after another
stream has finished. To obtain an actual four-way TG interval, a separate
Strata supplement primes the original four warmup prompts and replays them
twice from cache. Only28 input tokens total are reread per measured replay
(7 per stream, >99.9% reuse). It yields189.3065/187.6676tok/s over10.36/10.43s
four-way intervals. Its cached12.85/13.12s batch walls do not replace the
cold wall/PP results in the main table. Admission before the TG interval
therefore differs; the measured decode state remains four~20K contexts.
