# Native5802 rolling-contract candidate framework

CONFIG

Separate candidate snapshot of the original failing full native GDN oracle.
TP1, FP8 hybrid page geometry, packed control, physical columns [7,3,9,2],
128 recurrent calls, accepted pattern 1,2,3,4, all 12 original numerical gates.
The expectation remains rolling six-row convolution history in column zero.
The per-prefix diagnostic's successful completion is not a qualification gate.

COMMAND

After the runtime owner supplies immutable image and native SHA256 values,
run prepare.py with --image, --native-sha256, --pair-pass,
--pair-image-inspect, --build-evidence, --root and --output. All paths must
identify the new candidate experiment; the two output directories must not
exist. The build evidence file is required and frozen by hash. The original
failed snapshot is read-only input and its exact source hash is enforced.

The generated plan contains its exact launch command. Only the parent may
activate it after GPU allocation and the candidate's strict per-card plus
compiled pair preflight. No placeholder identity produces a prepared plan in
the real result tree. The framework tests use temporary fake identities only.

RESULT

CPU test_prepare.py passes against the retained actual oracle source. It proves
that only IMAGE and NATIVE_SHA assignments change in the source AST, all
geometry/math/history gates remain, dry run needs no GPU, and activation rejects
missing or wrong-image pair preflight receipts before any GPU operation.

The wrapper delegates serving-free oracle execution to the unchanged original
owned lifecycle: selected lease, production allocator, device pin, fresh cache,
8 GiB container, 420-second bound, cleanup verification and strict selected-card
post-health. Original PRE/POST byte-copy prerequisites remain. It adds a check
that pair preflight image-inspect identity matches the candidate and belongs to
the PASS marker's result tree. No pair reset is permitted under one lease.

MODEL LAUNCH

lease, validates inherited FD8, and passes --leased exactly once to the actual
server. test_model_lease.py exercises the actual server lease branch. The
original model_plan.py and failed plan remain historical evidence: their
nested lease attempt was stopped before output-directory creation or any GPU
work. Do not use that original model launcher.

oracle passes before activation. The Python legacy-layout adapter stays off.

checks teardown/health. Model qualification remains pending.
